# «Утро» — датчик под матрасом

Полное описание продукта: `../ПРОДУКТ-УТРО.md`
Что покупать: `../КОМПОНЕНТЫ-УТРО.md`

## Физика и её границы

Баллистокардиография: пьезоплёнка PVDF регистрирует механические толчки тела.
Дыхание — медленная крупная составляющая, сердце — быстрые слабые толчки.

**PVDF отдаёт заряд, то есть реагирует на изменение деформации, а не на её
величину. Статический вес человека плёнка не видит в принципе.** Отсюда
следует главное: пропажа дыхания на плёнке неотличима от ухода с кровати.
Поэтому ночная тревога **запрещена** без статического канала — это не
настройка, а проверяемое тестом свойство
(`test_night_alarm_impossible_without_load_channel`).

Статику дают тензодатчики под ножками кровати. Они же отвечают, сколько людей
в постели, и дают тренд веса — [Вероятно] клинически более ценный, чем пульс:
набор 2-3 кг за несколько дней это классический признак задержки жидкости.

## Отказ от числа — штатный результат

- Двое в постели → пульс не выдаётся. Выдать один пульс на двоих значит
  соврать.
- Шевеление в окне → витальные показатели недостоверны, окно не используется.
- Пульс по одному окну не принимается: агрегируется медианой по 15 минутам с
  требованием разброса не больше 12 уд/мин. Это позволяет использовать слабый
  сигнал, не снижая порог уверенности.

## Обработка

Чистый Python без numpy — намеренно: тот же алгоритм должен переноситься на
ESP32 в фиксированной точке. Фильтры — биквады (рецепты RBJ), спектр —
Гёрцель по сетке частот, никаких FFT-библиотек.

| Файл | Что делает |
|---|---|
| `dsp.py` | полосы, децимация, спектр, разбор окна |
| `presence.py` | слияние статики, динамики и PIR в состояние постели |
| `night.py` | накопление ночи, агрегация пульса, эпизоды |
| `digest.py` | утренняя сводка человеческим языком |
| `synth.py` | синтез сигнала для тестов и калибровки порогов |

Тесты: `python3 -m pytest tests/test_morning.py`

## Что не проверено на железе

Ни одна строка не работала с реальной плёнкой. Пороги уверенности подобраны на
синтетике и **обязаны быть перепроверены** на записях с конкретного матраса.
Процедура — в `../КОМПОНЕНТЫ-УТРО.md`, раздел «Этап 1».
