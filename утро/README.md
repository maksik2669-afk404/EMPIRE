# Утро

Всё, что относится к продукту «Утро», живёт здесь.

**Начни с этого:**
- [ПРОДУКТ-УТРО.md](ПРОДУКТ-УТРО.md) — суть, смысл, чего продукт НЕ делает, два открытых риска
- [КОМПОНЕНТЫ-УТРО.md](КОМПОНЕНТЫ-УТРО.md) — что покупать, в два этапа, с живыми ссылками

## Структура

| Папка | Что внутри |
|---|---|
| `morning/` | обработка сигнала плёнки, слияние с тензодатчиками, ночь, утренняя сводка |
| `eldercare/` | распорядок дня, лестница эскалации, измерение ложных тревог |
| `hub/` | центр принятий решений, воздух и температура, единая система |
| `firmware/` | прошивка и аналоговый тракт для этапа 1 |
| `tools/` | хост-инструменты: запись сигнала и прогон через DSP |

## Запуск

```bash
# Тесты (из корня репозитория)
python3 -m pytest tests/test_morning.py tests/test_eldercare.py tests/test_hub.py

# Измерение ложных тревог на симуляции 90 суток
python3 -m pytest tests/test_eldercare.py -k measured -q
cd утро && python3 -m eldercare.evaluate
```

Пакеты импортируются коротко (`from morning.dsp import ...`) — путь `утро` добавлен
в `pythonpath` в корневом `pytest.ini`.

## Что уже сделано и чем это подтверждено

| Утверждение | Чем проверено |
|---|---|
| 0 ложных тревог родне за 90 суток | `eldercare/evaluate.py`, симуляция |
| 0.5 опроса человека в день | там же |
| Все три сценария ЧП обнаружены | там же |
| Одно свидетельство в одиночку тревогу не поднимает | `tests/test_hub.py::test_every_single_signal_alone_stays_below_threshold` |
| Плёнка в одиночку не может поднять ночную тревогу | `tests/test_morning.py::test_night_alarm_impossible_without_load_channel` |
| Пульс при двух людях в постели не выдаётся | `tests/test_morning.py::test_two_people_detected_and_pulse_refused` |
| Беспокойный сон не даёт ложной тревоги | `tests/test_hub.py::test_restless_sleep_does_not_raise_an_alarm` |
