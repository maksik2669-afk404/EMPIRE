# EMPIRE Reply — ответы покупателям Wildberries, Ozon и Яндекс Маркета на любом языке

Telegram-бот для продавцов маркетплейсов:

1. Сам забирает новые **отзывы и вопросы** (WB — отзывы и вопросы; Ozon — отзывы и вопросы; Яндекс Маркет — отзывы).
2. Переводит их на язык продавца: русский, English, 中文, Türkçe, Қазақша, Oʻzbekcha.
3. Готовит ответ **на языке покупателя** с переводом для продавца.
4. Продавец жмёт «✅ Отправить», «✏️ Изменить» (пишет на своём языке, бот переводит), «🔄 Другой вариант» или «⏭ Пропустить».
5. Автоответ (по желанию) — только на отзывы 4–5★ или только 5★, и только если ответу не нужны факты о товаре. Вопросы и негатив автоматически не отправляются никогда.

Для кого: иностранные продавцы (Китай, Турция, Казахстан, Узбекистан), которые не читают по-русски, и российские продавцы с большим потоком отзывов, включая покупателей из стран СНГ.

## Быстрый старт (5 минут, без ключей маркетплейсов)

```bash
cp .env.example .env
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m app.crypto          # скопируйте вывод в FERNET_KEY
# впишите BOT_TOKEN от @BotFather; для демо без ИИ: LLM_PROVIDER=mock
.venv/bin/python -m app.main
```

В Telegram: `/start` → язык → `/connect` → **Demo**. Придут 5 тестовых карточек: негативный отзыв, отзыв без текста, вопросы на кыргызском и русском, отзыв на узбекском. Режим Demo подходит и для записи видео для краудфандинга.

## Продакшн на сервере в РФ

```bash
git clone <repo> && cd EMPIRE
cp .env.example .env   # заполните
docker compose up -d --build
docker compose logs -f
```

- **База данных** — SQLite в docker-томе `botdata`. Бэкап: `docker compose cp bot:/app/data/app.db ./backup.db`. Храните бэкап вместе с `FERNET_KEY`: без ключа база бесполезна.
- **ИИ — YandexGPT.** Yandex Cloud → каталог → сервисный аккаунт с ролью `ai.languageModels.user` → API-ключ. В `.env` впишите `YANDEX_API_KEY` и `YANDEX_FOLDER_ID` (ID каталога). OpenAI и Anthropic из РФ недоступны. Альтернатива — любой OpenAI-совместимый endpoint (`LLM_PROVIDER=openai`), например своя Qwen в vLLM/Ollama.
- **Telegram:** если `api.telegram.org` с сервера работает с перебоями, задайте `TELEGRAM_PROXY`.
- **Админ:** `ADMIN_IDS` = ваш Telegram ID. `/stats` — метрики для страницы проекта, `/grant <tg_id> <лимит>` — выдать тариф после оплаты.

## Ключи маркетплейсов (продавец отправляет их боту, бот сразу удаляет это сообщение)

| Маркетплейс | Что прислать | Где взять | Ограничения |
|---|---|---|---|
| Wildberries | токен | ЛК → Настройки → Доступ к API → категория «Вопросы и отзывы» | — |
| Ozon | `Client-Id Api-Key` | ЛК → Настройки → Seller API | **Отзывы и вопросы по API — только с подпиской Premium Plus/Pro** |
| Яндекс Маркет | `API-ключ businessId` | ЛК → Настройки → API и модули | В MVP только отзывы |

Ключи хранятся зашифрованными (Fernet/AES). Имена покупателей бот не сохраняет.

## Проверки

```bash
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest -q
```

Тесты покрывают запросы к API трёх маркетплейсов (пути, заголовки, тела, ретраи на 429, ошибки доступа), движок (дедупликация, автоответ, лимиты, возврат лимита при сбое ИИ, отправка без дублей) и сквозной сценарий бота с фейковым Telegram.

## Что проверено, а что — нет

- ✅ **Эндпоинты WB и Ozon** сверены с опубликованными SDK, сгенерированными из официальных OpenAPI-схем.
- ⚠️ **Эндпоинты Яндекс Маркета** (`goods-feedback`, `goods-feedback/comments/update`) написаны по документации без сверки со схемой. Первое подключение реального кабинета сразу покажет ошибку, если что-то не так.
- ⚠️ **Реальные ключи и живой YandexGPT не тестировались** — песочница разработки не имеет доступа к API из РФ. Перед запуском пилота подключите свой магазин и прогоните 20–30 реальных отзывов.

## Юридический минимум (РФ)

- Тексты отзывов могут содержать персональные данные. Вы — оператор ПДн: уведомление в Роскомнадзор, политика обработки ПДн, сервер и БД в РФ (152-ФЗ).
- Оферта и политика конфиденциальности для продавцов обязательны до приёма денег.
- Правила маркетплейсов запрещают в ответах ссылки, контакты и просьбы изменить оценку. Бот блокирует автоотправку таких ответов, но ответственность за отправленный текст остаётся на продавце.

## Архитектура

```
app/
  marketplaces/  wildberries.py ozon.py yandex_market.py demo.py  — клиенты API, общий ретрай/ошибки
  llm/           YandexGPT, OpenAI-совместимый, Mock
  ai.py          промпты, разбор JSON, защита от контактов в ответах
  service.py     движок: опрос → черновик → уведомление/автоответ → отправка (не зависит от Telegram)
  bot/           aiogram 3: онбординг, карточки, настройки, админка; тексты ru/en/zh
  db.py          SQLite
```

Если Telegram заблокируют, достаточно написать новый `Notifier` — для MAX-бота или веб-кабинета. Движок, маркетплейсы и ИИ останутся без изменений.
