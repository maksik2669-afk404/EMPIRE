# WINTER ARC — трекер привычек в Google Таблицах с входом по паролю

Покупатель открывает вашу ссылку, вводит пароль и нажимает «❄ Скопировать себе». Google создаёт ему личную копию таблицы. Внутри три листа:

- **❄ СТАРТ** — как пользоваться, правила арки и 3 цели;
- **❄ HIM** и **❄ HER** — трекеры на 92 дня (01.10–31.12).

В каждом трекере:
- 8 привычек с галочками — их можно переименовать прямо в заголовке;
- процент выполнения за день и полоска ▰▰▰▱▱;
- общий прогресс, серия дней подряд, лучшая серия и отсчёт до финиша;
- сон, вес, настроение и заметка дня;
- подсветка сегодняшнего дня.

Оформление холодное: ночь, лёд, иней.

## Установка (5–10 минут, один раз)

1. Откройте https://script.google.com → **Новый проект**.
2. Вставьте содержимое `Code.gs` в файл `Code.gs`.
3. **Файлы → + → HTML**, имя `Gate` → вставьте содержимое `Gate.html`.
4. В начале `Code.gs` поменяйте пароль: `PASSWORDS: ['ВАШ-ПАРОЛЬ']`.
5. Выберите функцию **setup** → **Выполнить** → разрешите доступ.
   Если Google покажет «Приложение не проверено»: **Дополнительно → Перейти в проект**. Это ваш собственный скрипт.
6. Готово: на вашем Диске появилась таблица-шаблон, ссылки на неё — в «Журнале выполнения».
7. **Начать развёртывание → Новое развёртывание** → ⚙ → **Веб-приложение**:
   - «Запуск от имени»: **Я**;
   - «У кого есть доступ»: **Все**.

   Ссылка вида `.../exec` — это ваш мини-сервис. Её вместе с паролем вы и даёте покупателям.

## Как менять

- **Пароль или текст страницы:** правите код → **Управление развёртываниями → ✎ → Версия: новая версия**. Без новой версии страница не обновится.
- **Привычки, даты, порог 80%:** блоки `CONFIG` и `PROFILES` в начале `Code.gs`. После правки снова запустите `setup`: создастся новый шаблон, и страница начнёт выдавать его. Старый шаблон удалите вручную.
- **Статистика:** запустите функцию `stats`. Число успешных входов будет в журнале.

## Честно об ограничениях

- В Google Таблицах нет пароля на документ. Пароль защищает только страницу входа. Ссылку «Создать копию» после входа можно переслать другому человеку, и закрыть это нельзя.
- Шаблон доступен всем по ссылке только для чтения — иначе Google не даст сделать копию. Редактировать его можете только вы.
- Покупателю нужен Google-аккаунт.

## Проверка без Google

```bash
node test/mock-run.js
```

Скрипт прогоняет `Code.gs` на имитации Google Таблиц. Он проверяет 475 формул на синтаксис, размеры всех диапазонов, закрепление строк, проверку пароля и подстановки на странице входа.
