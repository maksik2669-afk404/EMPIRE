# Сметчик — папка для сервера

Здесь всё, что нужно боту: код, справочники и установщик. Ничего не надо собирать и
настраивать руками — установщик спросит токен и сделает остальное.

## Что понадобится

1. **Сервер** с Ubuntu 22.04 или 24.04 (1 ядро, 1 ГБ памяти достаточно) и доступ `root`.
2. **Токен бота**: в Телеграме @BotFather → `/newbot` → скопировать токен.
3. Для мини-аппа — открытые порты **80 и 443** на сервере (у большинства хостингов открыты).
   Домен покупать не обязательно: установщик предложит бесплатный адрес вида `1-2-3-4.sslip.io`.
4. По желанию — **токен оплаты**: @BotFather → ваш бот → Payments → ЮKassa (или другой провайдер).
   Без него бот принимает оплату в Telegram Stars.

## Установка — 3 шага

**1. Скопируйте эту папку на сервер.**

- Windows: программа WinSCP → подключиться к серверу → перетащить папку `smeta-server` в `/opt/`.
- Mac / Linux: `scp -r smeta-server root@IP_СЕРВЕРА:/opt/`

**2. Подключитесь к серверу:** `ssh root@IP_СЕРВЕРА` (в Windows — PowerShell).

**3. Запустите установщик:**

```bash
cd /opt/smeta-server && sudo bash install.sh
```

Он спросит токен бота, ваш Telegram ID, токен оплаты (можно пропустить) и включать ли мини-апп.
Через минуту бот работает: откройте его в Телеграме и нажмите `/start`.

## Что делает установщик

- ставит Python, шрифты для PDF и библиотеки (в отдельное окружение `.venv`);
- записывает ключи в `.env` (доступ только у root);
- для мини-аппа ставит Caddy и получает HTTPS-сертификат автоматически;
- регистрирует службу `smeta-bot` с автозапуском после перезагрузки;
- включает ежедневный бэкап базы, логотипов и ключей в `/root/smeta-backups` (хранится 14 копий).

Повторный запуск `install.sh` безопасен: ключи и база сохраняются.

## Управление

| Что | Команда |
|---|---|
| Лог в реальном времени | `journalctl -u smeta-bot -f` |
| Перезапуск | `systemctl restart smeta-bot` |
| Остановить | `systemctl stop smeta-bot` |
| Обновить код | скопировать новую папку поверх старой → `sudo bash update.sh` |
| Бэкап вручную | `sudo bash backup.sh` |
| Загрузить полную ФСНБ-2022 | `.venv/bin/python -m smeta.fgis load /путь/ФСНБ.zip --kind rates` |
| Загрузить индексы ФГИС ЦС | `.venv/bin/python -m smeta.fgis load /путь/индексы.xlsx --kind indices` |
| Выдать подписку вручную | в боте: `/grant TG_ID ДНЕЙ` (только админ) |

Восстановление из бэкапа: распаковать архив в папку бота, переименовать
`data/smeta.backup.db` в `data/smeta.db`, `systemctl restart smeta-bot`.

## Если что-то не так

- **«Телеграм не принял токен или недоступен с сервера»** — проверьте токен. Если токен
  верный, а сервер не видит `api.telegram.org`, впишите прокси в `.env`:
  `TELEGRAM_PROXY=socks5://user:pass@host:port` и `systemctl restart smeta-bot`.
- **Мини-апп не открывается** — проверьте, что порты 80 и 443 открыты в панели хостинга,
  и посмотрите `journalctl -u caddy -n 50`. Первый сертификат выдаётся до минуты.
- **Оплата не проходит** — токен провайдера в `.env` (`SMETA_PAYMENT_TOKEN`) должен быть
  от того же бота. Для ЮKassa с онлайн-кассой поставьте `SMETA_PAYMENT_RECEIPT=1`.

## Что внутри

- `smeta/` — код бота и мини-аппа
- `data/` — справочники: демо-расценки, НР/СП, индексы, коэффициенты, лимитированные
  затраты, шаблоны смет, нормы расхода материалов, ставки налогов, тарифы подписки.
  Всё это — обычные CSV, правятся в Excel без программиста.
- `install.sh`, `update.sh`, `backup.sh` — установка, обновление, бэкап
- `env.example` — описание всех настроек

> Демо-расценки — не ФЕР. Для настоящих смет загрузите ФСНБ-2022 и индексы ФГИС ЦС
> (команды выше или файлом прямо в бота: «📚 Справочники» → «📥 Загрузить файл»).
