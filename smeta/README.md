# Сметчик — бот, который считает смету из обычного текста

Telegram-бот (и CLI) для подрядчиков и бригадиров: человек вбивает работы словами, бот
находит расценку, считает накладные расходы, сметную прибыль и НДС и отдаёт готовый
**Excel или PDF с шапкой компании** (название, ИНН, КПП, номер сметы, заказчик, объект,
подпись). Смету можно срезать или поднять на процент, подогнать под сумму, а отдельно —
только для себя — посмотреть **маржу и экономию на материалах**.

```
штукатурка стен 120 м2            ✅ расценка из справочника
стяжка пола 85 м2 по 700          💬 цена заказчика
плитка 2,7х4,2 м2 х 1500          ✅ перемножил размеры
мат: керамогранит 22 м2           🧾 цена из прайса поставщика
розетки 24 точки                  ✅
подшив сайдингом 30 м2            ❓ нет в справочнике — спросит цену
```

## Посмотреть результат за минуту (без Telegram)

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m smeta.cli --demo --profit \
  --company 'ООО «СтройПро»' --inn 7707083893 --signer 'Иванов И.И.' \
  --customer 'ООО «Ромашка»' --object 'г. Москва, ул. Ленина, 5' --cut 20
```

В консоли — разбор строк, смета и маржа; в `data/export/` — `СМ-2026-0001.xlsx`,
`СМ-2026-0001.pdf` и внутренний `СМ-2026-0001-профит.xlsx`.

## Установка на сервер

Готовая папка — [`smeta-server/`](../smeta-server/README.md) в корне репозитория: скопировать
на сервер и выполнить `sudo bash install.sh`. Установщик спросит токен бота, поставит
зависимости, HTTPS для мини-аппа (Caddy, домен или бесплатный `IP.sslip.io`), службу
с автозапуском и ежедневный бэкап. Папка собирается из исходников командой
`bash deploy/smeta/build.sh` — руками её не правят.

Локально, для разработки:

```bash
cp deploy/smeta/env.example .env      # впишите SMETA_BOT_TOKEN от @BotFather
set -a; . ./.env; set +a; .venv/bin/python -m smeta.bot
```

## Интерфейс бота

Всё делается кнопками из главного меню; набирать команды не нужно.

- **Главное меню:** новая смета, мои сметы, продолжить текущую, обмер, шаблоны, проверка
  чужой сметы, налоги, воронка, компания, справочники, подписка, помощь, мини-апп.
- **У каждого экрана** — «⬅️ Назад» и «🏠 Меню». «Назад» возвращает ровно по пройденному пути
  (смета → позиции → карточка → скидка → назад → карточка…), а не в случайное место.
- **Ввод — мастерами по шагам:** «Шаг 2 из 7», на каждом шаге «⬅️ Назад» к предыдущему
  вопросу, «⏭ Пропустить» для необязательных, кнопки быстрых ответов (высота 2,5 / 2,7 / 3,0).
  Ошибка ввода (неверный ИНН, буквы вместо числа) не сбрасывает мастер — бот переспрашивает.
- **Экраны подстраиваются:** у пустой сметы — только «добавить / обмер / шаблон»; акты —
  когда есть что закрывать; кнопка мини-аппа — когда он включён.
- Внизу постоянно висят кнопки «🏠 Меню» и «🧮 Текущая смета». Любой текст вне мастера —
  это работы для текущей сметы.

## Мини-апп в Телеграме

Включается, если задан `SMETA_WEBAPP_URL` (https). Открывается кнопкой меню бота
(«📱 Сметчик») и кнопкой «📱 Открыть приложение» в главном меню.

- Вкладки: 🧮 Сметы · 📐 Обмер · 🏗 Шаблоны · 🧾 Налоги; системная кнопка Телеграма «Назад».
- Смета: итоги, позиции (касание — правка объёма, цены, ставки бригады, выполнения),
  добавление работ текстом, скидка/наценка, подгон под сумму, статус, материалы по нормам.
- Документы (Excel, PDF, КП, наряд, маржа) бот присылает в чат — так они открываются и
  пересылаются на любом телефоне.
- Цвета берутся из темы Телеграма пользователя (светлая/тёмная).
- Безопасность: каждый запрос подписан Телеграмом (initData, HMAC по токену бота) и
  проверяется на свежесть; чужие сметы недоступны даже по прямому номеру — закрыто тестами.

## Команды

| Команда | Что делает |
|---|---|
| `/company` | шапка: название, ИНН, КПП, адрес, телефон, подписант (один раз) |
| `/new` | новая смета: объект, заказчик; номер присваивается сам (`СМ-2026-0007`) |
| текст | добавить работы — по одной в строке |
| `/smeta` | показать смету с итогами |
| `/cut 20` · `/up 15` | срезать / поднять на процент (`/cut 20 работы` — только работы) |
| `/fit 900000` | подогнать итог под сумму |
| `/reset` | убрать все корректировки |
| `/price 4 1500` · `/qty 4 85` · `/del 4` | править позицию по номеру |
| `/vat 0` | смета без НДС (УСН); `/vat 20` — с НДС |
| `/nr off` | не считать накладные расходы частью себестоимости (вариант для бригады) |
| `/xlsx` · `/pdf` | файл заказчику |
| `/profit` | маржа, экономия на материалах, нал/безнал — **только вам** |
| `/nalog` | налоги по смете: УСН 6/15, ОСНО (ООО и ИП), НПД и сколько останется |
| `/nalog 18000000 ип` | то же с годовым доходом и формой — точнее по лимитам и НДС |
| `/nalog_rates` | какие ставки применяются и где они лежат |
| `/rates плитка` | поиск по справочнику расценок |
| `/index` | индекс пересчёта в текущие цены (ФГИС ЦС) |
| `/base` | какой справочник используется: своя база или демо |
| `/import` | загрузить ФСНБ-2022, индексы или прайс (CSV, XLSX, XML, DBF, ZIP) |
| `/list` · `/open 12` | мои сметы |

## Как считается

Для позиции из справочника (нормативный расчёт):

```
объём → в измеритель расценки        85 м2 при расценке «100 м2» → 0,85
ПЗ  = ОТ·Иот + ЭМ·Иэм + МАТ·Имат     прямые затраты в текущих ценах
НР  = (ОТ + ЗПМ) · норматив НР       накладные расходы
СП  = (ОТ + ЗПМ) · норматив СП       сметная прибыль
Итого по позиции = (ПЗ + НР + СП) · коэффициент корректировки
```

Для позиции по договорной цене: `объём × цена × коэффициент корректировки`.
Дальше — НДС (20 % или 0 % для УСН) и итог. Все деньги считаются в `Decimal` и
округляются до копеек; подгон под сумму (`/fit`) попадает в цель до копейки (если из-за округления НДС ровно такая копейка недостижима — берётся ближайшая, расхождение не больше 1 коп.).

**Рез не уменьшает себестоимость.** Себестоимость позиции всегда считается без
корректировок, поэтому после `/cut 30` бот прямо пишет, какие позиции ушли ниже
себестоимости и на сколько. Это главное, чего нет в обычных сметных программах:
подрядчик видит не только «минус 30 %», но и то, что он после этого работает в убыток.

## Загрузка ФСНБ-2022 и индексов ФГИС ЦС

Официальные данные в репозитории не лежат и лежать не могут — их выгружает владелец бота.
Импортёр не привязан к одной раскладке файла: он сам находит строку заголовка, распознаёт
столбцы по смыслу и **показывает отчёт** — что сопоставил, сколько строк взял, что
пропустил и почему. Молчаливый импорт хуже упавшего.

Поддерживаются **XLSX, XML, DBF, CSV/TSV и ZIP** с любым из них (архив разбирается
целиком), кодировки UTF-8, Windows-1251 и CP866, двухуровневые шапки и строки-разделы.

```bash
# 1. проверить, что сервер видит портал (на сервере, не на ноутбуке)
python3 -m smeta.fgis check 'https://fgiscs.minstroyrf.ru/...'

# 2. скачать и сразу импортировать расценки
python3 -m smeta.fgis fetch 'https://fgiscs.minstroyrf.ru/...' --kind rates

# если портал требует авторизацию — скопируйте Cookie из браузера
python3 -m smeta.fgis fetch '<ссылка>' --kind rates --header 'Cookie: session=...'

# 3. то же для индексов по элементам затрат
python3 -m smeta.fgis fetch '<ссылка на индексы>' --kind indices

# уже скачанный файл
python3 -m smeta.fgis load ~/ФСНБ-2022.zip --kind rates
python3 -m smeta.fgis load ~/индексы_IV_кв.xlsx --kind indices --append
```

Результат: `data/rates/fer.csv` и `data/rates/indices_fgis.csv` — канонический CSV,
который бот читает при запуске. Проверить отдельно, без записи:

```bash
python3 -m smeta.importer ~/ФСНБ-2022.zip --kind rates --limit 20
```

Файлы до 20 МБ можно просто прислать боту в чат (`/import`) — он ответит тем же отчётом.
Больше 20 МБ Телеграм боту не отдаёт, поэтому полная база грузится командой на сервере.

**После первого импорта своих расценок демо-база автоматически отключается**, чтобы
придуманные цены не попали в реальную смету. Вернуть обе: `/base оба`.

Индекс пересчёта выбирается командой `/index`: бот покажет список загруженных индексов
(регион, вид строительства, период, ИОТ/ИЭМ/ИМАТ) и применит выбранный к смете.

### Что ещё надо подставить своё

| Файл | Что это | Что сделать |
|---|---|---|
| `data/rates/demo_rabota.csv` | **49 демо-расценок** в текущих ценах. Это **не ФЕР** | заменить импортом ФСНБ-2022 (выше) |
| `data/rates/nr_sp.csv` | нормативы НР и СП по видам работ — **демо-значения** | сверить с приказом Минстроя России № 812/пр |
| `data/rates/sbornik_work_type.csv` | номер сборника ФЕР → вид работ (чтобы НР/СП ставились сами) | дополнить под свои сборники |
| `data/rates/indices.csv` | индексы пересчёта (демо) | загрузить индексы ФГИС ЦС |
| `data/tax/rates.csv` | ставки и лимиты налогов по годам | сверить перед сдачей клиентам: пороги индексируются |
| `data/suppliers/demo.csv` | прайс поставщиков: прайс, скидка, розница, нал/безнал | завести свои договорённости |

Формат импорта расценок (разделитель `;`, UTF-8 или Windows-1251; принимаются и
английские, и официальные заголовки вида «Оплата труда рабочих, руб.»):

```
Шифр;Наименование;Ед.изм.;ОТ;ЭМ;ЗПМ;МАТ;ТЗ;Вид работ;Ключевые слова
ФЕР08-02-001-01;Кладка перегородок из кирпича;100 м2;31000.40;2100.00;640.00;18400.10;310.2;каменные;кирпич перегородка
```

Формат прайса:

```
material;unit;price;discount;retail;supplier;inn;payment;min_qty;note;keywords
Керамогранит 600х600;м2;1150;25;1550;ТД Плитка;7736050003;безнал;30;;плитка керамогранит
```

`price` — прайс поставщика, `discount` — ваша скидка (%), `retail` — цена, которая попадёт
в смету заказчику. Разница — ваша экономия, она видна только в `/profit`.

## Налоги

`/nalog` берёт текущую смету, достаёт из неё выручку, НДС, закупку материалов и ФОТ и
считает **все режимы сразу**: УСН 6 %, УСН 15 % (с минимальным налогом), ОСНО для ООО
(НДС с вычетом входного + налог на прибыль), ОСНО для ИП (НДС + прогрессивный НДФЛ +
взносы за себя), НПД. Для каждого — налоги построчно, нагрузка в процентах и сколько
останется на руки; недоступные режимы помечаются причиной (лимит дохода, работники).

Учитываются: НДС на УСН при доходе выше порога (5 / 7 %), уменьшение налога на страховые
взносы (до 50 %, а для ИП без работников — полностью), предельная база взносов,
фиксированные взносы ИП и 1 % с превышения, взносы на травматизм.

Ставки и лимиты — в `data/tax/rates.csv`, по строке на значение, с годом. Бот всегда
печатает, ставки какого года применил, и если файла на нужный год нет — говорит об этом
прямо, а не считает молча по устаревшим.

## Что уходит заказчику, а что остаётся вам

| | Excel/PDF заказчику | `/profit` и файл маржи |
|---|---|---|
| Состав работ, объёмы, цены, НР, СП, НДС, шапка, подписи | ✅ | ✅ |
| Закупочные цены, скидки, названия поставщиков, нал/безнал, маржа | ❌ никогда | ✅ |

Файл маржи помечен сверху «ДЛЯ ВНУТРЕННЕГО ИСПОЛЬЗОВАНИЯ — НЕ ОТПРАВЛЯТЬ ЗАКАЗЧИКУ».
Это разделение закрыто тестом `test_xlsx_never_leaks_purchase_prices`.

## Ограничения — прочитать до того, как показывать клиентам

1. **Это не форма для госзаказа.** Выгрузка — читаемая локальная смета, но не форма № 4
   приказа Минстроя № 421/пр и не файл для экспертизы (`.gge`, `.xml`). Для бюджетных
   объектов нужна аттестованная программа (ГРАНД-Смета и т.п.).
2. **Расценки и нормативы в репозитории — демонстрационные.** До загрузки официальной
   ФСНБ и нормативов 812/пр цифры нельзя предъявлять заказчику как ФЕР.
3. **Подбор расценки — нечёткий поиск по словам**, а не экспертиза. Бот показывает процент
   совпадения и помечает ❓ и ⚠️ там, где не уверен; состав работ всё равно проверяет человек.
4. **Маржа на материалах — законный интерес подрядчика при твёрдой цене.** Но если вы
   закупаете материал как агент заказчика (по его деньгам, с отчётом), скрытая разница —
   это уже спор об убытках, а в худшем случае ст. 204 УК РФ. Схемы «нал со скидкой» через
   юрлиц бот не обслуживает: в прайсе есть пометка оплаты, но ни учёта, ни документов для
   таких схем здесь нет и не будет.
5. **Данные.** SQLite, по умолчанию `data/smeta.db`, без шифрования. ИНН и названия
   заказчиков — персональные/коммерческие данные: сервер в РФ, бэкап, доступ по ключу.
