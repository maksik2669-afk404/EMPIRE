# Сметчик — бот, который считает смету из обычного текста

Telegram-бот (и CLI) для подрядчиков и бригадиров: человек вбивает работы словами, бот
находит расценку, считает накладные расходы, сметную прибыль и НДС и отдаёт готовый
**Excel или PDF с шапкой компании** (название, ИНН, КПП, номер сметы, заказчик, объект,
подпись). Смету можно срезать или поднять на процент, подогнать под сумму, а отдельно —
только для себя — посмотреть **маржу и экономию на материалах**.

```
штукатурка стен 120 м2            ✅ расценка из справочника
стяжка пола 85 м2 по 700          💬 цена заказчика
плитка 2,7х4,2 м2 х 1500          ✅ перемножил размеры
мат: керамогранит 22 м2           🧾 цена из прайса поставщика
розетки 24 точки                  ✅
подшив сайдингом 30 м2            ❓ нет в справочнике — спросит цену
```

## Посмотреть результат за минуту (без Telegram)

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m smeta.cli --demo --profit \
  --company 'ООО «СтройПро»' --inn 7707083893 --signer 'Иванов И.И.' \
  --customer 'ООО «Ромашка»' --object 'г. Москва, ул. Ленина, 5' --cut 20
```

В консоли — разбор строк, смета и маржа; в `data/export/` — `СМ-2026-0001.xlsx`,
`СМ-2026-0001.pdf` и внутренний `СМ-2026-0001-профит.xlsx`.

## Запуск бота

```bash
cp .env.example .env          # впишите SMETA_BOT_TOKEN от @BotFather
.venv/bin/python -m smeta.bot
```

Служба на сервере (Ubuntu):

```ini
# /etc/systemd/system/smeta-bot.service
[Unit]
Description=Smeta bot
After=network-online.target
[Service]
WorkingDirectory=/opt/EMPIRE
EnvironmentFile=/opt/EMPIRE/.env
ExecStart=/opt/EMPIRE/.venv/bin/python -m smeta.bot
Restart=always
[Install]
WantedBy=multi-user.target
```

## Команды

| Команда | Что делает |
|---|---|
| `/company` | шапка: название, ИНН, КПП, адрес, телефон, подписант (один раз) |
| `/new` | новая смета: объект, заказчик; номер присваивается сам (`СМ-2026-0007`) |
| текст | добавить работы — по одной в строке |
| `/smeta` | показать смету с итогами |
| `/cut 20` · `/up 15` | срезать / поднять на процент (`/cut 20 работы` — только работы) |
| `/fit 900000` | подогнать итог под сумму |
| `/reset` | убрать все корректировки |
| `/price 4 1500` · `/qty 4 85` · `/del 4` | править позицию по номеру |
| `/vat 0` | смета без НДС (УСН); `/vat 20` — с НДС |
| `/nr off` | не считать накладные расходы частью себестоимости (вариант для бригады) |
| `/xlsx` · `/pdf` | файл заказчику |
| `/profit` | маржа, экономия на материалах, нал/безнал — **только вам** |
| `/rates плитка` | поиск по справочнику расценок |
| `/import` | загрузить свои расценки (ФЕР) или прайс поставщика в CSV |
| `/list` · `/open 12` | мои сметы |

## Как считается

Для позиции из справочника (нормативный расчёт):

```
объём → в измеритель расценки        85 м2 при расценке «100 м2» → 0,85
ПЗ  = ОТ·Иот + ЭМ·Иэм + МАТ·Имат     прямые затраты в текущих ценах
НР  = (ОТ + ЗПМ) · норматив НР       накладные расходы
СП  = (ОТ + ЗПМ) · норматив СП       сметная прибыль
Итого по позиции = (ПЗ + НР + СП) · коэффициент корректировки
```

Для позиции по договорной цене: `объём × цена × коэффициент корректировки`.
Дальше — НДС (20 % или 0 % для УСН) и итог. Все деньги считаются в `Decimal` и
округляются до копеек; подгон под сумму (`/fit`) попадает в цель **точно**.

**Рез не уменьшает себестоимость.** Себестоимость позиции всегда считается без
корректировок, поэтому после `/cut 30` бот прямо пишет, какие позиции ушли ниже
себестоимости и на сколько. Это главное, чего нет в обычных сметных программах:
подрядчик видит не только «минус 30 %», но и то, что он после этого работает в убыток.

## Справочники: что в репозитории и что надо подставить своё

| Файл | Что это | Что сделать |
|---|---|---|
| `data/rates/demo_rabota.csv` | **49 демо-расценок** на работы в текущих ценах. Это **не ФЕР** и не официальная база | выгрузить ФСНБ-2022 (ФЕР) из ФГИС ЦС и загрузить через `/import` |
| `data/rates/nr_sp.csv` | нормативы НР и СП по видам работ — **демо-значения** | заменить на нормативы приказа Минстроя России № 812/пр для вашего вида работ |
| `data/rates/indices.csv` | индексы пересчёта базисных цен в текущие | взять квартальные индексы ФГИС ЦС по своему региону |
| `data/suppliers/demo.csv` | прайс поставщиков: прайс, скидка, розница, нал/безнал | завести свои договорённости, загрузить через `/import` |

Формат импорта расценок (разделитель `;`, UTF-8 или Windows-1251; принимаются и
английские заголовки):

```
Шифр;Наименование;Ед.изм.;ОТ;ЭМ;ЗПМ;МАТ;ТЗ;Вид работ;Ключевые слова
ФЕР08-02-001-01;Кладка перегородок из кирпича;100 м2;12345.67;890.12;120.00;0;310;каменные;кирпич перегородка
```

Формат прайса:

```
material;unit;price;discount;retail;supplier;inn;payment;min_qty;note;keywords
Керамогранит 600х600;м2;1150;25;1550;ТД Плитка;7736050003;безнал;30;;плитка керамогранит
```

`price` — прайс поставщика, `discount` — ваша скидка (%), `retail` — цена, которая попадёт
в смету заказчику. Разница — ваша экономия, она видна только в `/profit`.

## Что уходит заказчику, а что остаётся вам

| | Excel/PDF заказчику | `/profit` и файл маржи |
|---|---|---|
| Состав работ, объёмы, цены, НР, СП, НДС, шапка, подписи | ✅ | ✅ |
| Закупочные цены, скидки, названия поставщиков, нал/безнал, маржа | ❌ никогда | ✅ |

Файл маржи помечен сверху «ДЛЯ ВНУТРЕННЕГО ИСПОЛЬЗОВАНИЯ — НЕ ОТПРАВЛЯТЬ ЗАКАЗЧИКУ».
Это разделение закрыто тестом `test_xlsx_never_leaks_purchase_prices`.

## Ограничения — прочитать до того, как показывать клиентам

1. **Это не форма для госзаказа.** Выгрузка — читаемая локальная смета, но не форма № 4
   приказа Минстроя № 421/пр и не файл для экспертизы (`.gge`, `.xml`). Для бюджетных
   объектов нужна аттестованная программа (ГРАНД-Смета и т.п.).
2. **Расценки и нормативы в репозитории — демонстрационные.** До загрузки официальной
   ФСНБ и нормативов 812/пр цифры нельзя предъявлять заказчику как ФЕР.
3. **Подбор расценки — нечёткий поиск по словам**, а не экспертиза. Бот показывает процент
   совпадения и помечает ❓ и ⚠️ там, где не уверен; состав работ всё равно проверяет человек.
4. **Маржа на материалах — законный интерес подрядчика при твёрдой цене.** Но если вы
   закупаете материал как агент заказчика (по его деньгам, с отчётом), скрытая разница —
   это уже спор об убытках, а в худшем случае ст. 204 УК РФ. Схемы «нал со скидкой» через
   юрлиц бот не обслуживает: в прайсе есть пометка оплаты, но ни учёта, ни документов для
   таких схем здесь нет и не будет.
5. **Данные.** SQLite, по умолчанию `data/smeta.db`, без шифрования. ИНН и названия
   заказчиков — персональные/коммерческие данные: сервер в РФ, бэкап, доступ по ключу.
