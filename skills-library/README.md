# Библиотека навыков

`pdm/` — 130 навыков продакт-менеджера (PRD, roadmap, воронки, ценообразование, юнит-экономика, маркетплейсы, GTM…) из открытого репозитория [Anton-Creates/pdm-skills-agent](https://github.com/Anton-Creates/pdm-skills-agent), коммит `c955209` (11.09.2026). Лицензия MIT — см. `pdm/LICENSE`; авторство и лицензию при распространении сохранять.

Навыки лежат здесь **неактивными**, чтобы не загружать описания всех 130 в каждую сессию. Активные — только те, что скопированы в `.claude/skills/`.

## Как пользоваться

- Найти навык: `pdm/INDEX.md` (таблица: группа, домен, что делает) или `pdm/SKILL_MAP.md`.
- Подключить: напишите Claude «подключи навык funnel-analysis» — или сами: `skills-library/use-skill.sh funnel-analysis`.
- Отключить: `skills-library/use-skill.sh --remove funnel-analysis`. Посмотреть подключённые: `--list`.
- Английская версия: `--en`.

Перед подключением Claude читает навык целиком: это чужие инструкции, которые он потом будет выполнять.

## Важно знать

- Заявленные на сайте «130/130 протестировано» — оценка объёма и оформления ответов формулой; реальную проверку качества прошли 7 навыков (`prd`, `roadmap`, `user-stories`, `prioritize`, `okr-writer`, `credit-product-spec`, `c2c-dynamics`).
- `unit-economics` — только для финтеха. Для подписок — `subscription-economics`, для продавцов маркетплейсов — `seller-economics`.
- `GLOBAL_RULES.md`, `METRICS_TAXONOMY.md`, `AGENTS.md` — общие правила автора; не подключены, можно взять в работу при желании.

## Обновить до свежей версии

Попросите Claude: «обнови библиотеку pdm-skills» — он скачает репозиторий заново и заменит `pdm/skills`, оставив подключённые навыки как есть.
