# Спецификация инвестиционных и финансовых маркетплейсов (finmarket-spec)

Спроектировать платформу финансового супермаркета (финансовый маркетплейс по 211-ФЗ / регистратор финансовых транзакций): витрина вкладов, кредитов, страховок и облигаций с онлайн-оформлением без визита в банк.

## Процесс

1. **Определи архитектуру интеграции с финансовыми организациями:** Открытые банковские API (Open Banking), защищенный протокол обмена заявками и ставками в реальном времени.
2. **Спроектируй сквозную идентификацию через РФТ / Госуслуги:** Однократная идентификация клиента через ЕБС / представителя маркетплейса для открытия продуктов в любых банках.
3. **Разработай независимый агрегатор и калькулятор доходности:** Честное сравнение эффективных процентных ставок по вкладам с учетом капитализации, налогов и условий снятия.
4. **Опиши юридический контур оформления договоров:** Электронное подписание через РФТ (Регистратор финансовых транзакций), гарантирующее юридическую силу сделки.
5. **Заложи защиту от конфликта интересов:** Прозрачные правила ранжирования предложений финансовых организаций без скрытого фаворитизма спонсоров.
6. **Сохрани артефакт** в текущей рабочей директории как `finmarket-spec-[контекст].md`.

| [2. Идентификация] | [Подтверждение через Госуслуги / ЕСИА] | [Передача цифрового профиля в банк] | [Проверка валидности KYC статуса] |

### 2. Спецификация честного калькулятора вкладов
- **Расчет чистой доходности:** Учет ежемесячной капитализации процентов и удержания налога на процентные доходы (НДФЛ).
- **Сравнение условий:** Отображение условий досрочного расторжения, минимальной суммы и возможности пополнения.
- **Маркировка АСВ:** Обязательный бейдж страхования вкладов АСВ (до 1.4 млн руб на один банк).

### 3. Метрики эффективности финансового маркетплейса
- **Marketplace Application-to-Funded Rate:** Конверсия из подачи заявки в фактическое пополнение финансового продукта.
- **Average Deposit / Loan Amount:** Средний чек открытого через маркетплейс финансового продукта.
- **Open Banking API Success Rate:** Процент успешных синхронных обменов с банковскими бэкендами.
- **Repeat Product Purchase Rate:** Доля клиентов, открывших 2 и более продукта в разных банках через платформу.

## Правила

- Запрещено взимать скрытые комиссии с пользователя за открытие вклада или оформление кредита через платформу.
- Каждая сделка обязана регистрироваться в государственном Регистраторе финансовых транзакций (РФТ).
- Платформа требует обязательного наличия явного предупреждения о лимитах страхования вкладов АСВ.
- Не допускай манипуляций с порядком отображения финансовых предложений без явного указания рекламного статуса.
- Максимальное время открытия депозита и получения подтверждения от банка не должно превышать 3 минут.
