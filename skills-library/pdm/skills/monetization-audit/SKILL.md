# Аудит и оптимизация модели монетизации SaaS (monetization-audit)

Спроектировать аудит ценообразования, тарифной сетки, упаковок фич (Packaging) и метрик монетизации для B2B и B2C SaaS продуктов. Скилл помогает выявить недомонетизированные сегменты, устранить каннибализацию тарифов и настроить метрики ценности (Value Metrics).

## Процесс

1. **Определи ключевую метрику ценности (Value Metric):** Выбери драйвер роста цены (Seats, Storage, API Calls, Monthly Active Users, Revenue processed), прямо коррелирующий с ценностью продукта.
2. **Проведи аудит упаковки фич по тарифам (Feature Packaging):** Анализ распределения фич по корзинам: Leaders (драйверы покупки), Fillers (дополнения), Killers (фичи, убивающие конверсию при неправильном позиционировании).
3. **Оцени эластичность цен и готовность платить (Willingness to Pay):** Методология Van Westendorp (Price Sensitivity Meter) и опросник Gabor-Granger для поиска оптимальной цены.
4. **Спроектируй стратегию перехода на новые цены (Grandfathering):** План повышения цен для существующих клиентов без всплеска оттока (сохранение старой цены на 6-12 месяцев).
5. **Сформируй модель перехода от Freemium к Free Trial:** Оценка конверсий и экономики воронки при смене модели бесплатного доступа.
6. **Сохрани артефакт** в текущей рабочей директории как `monetization-audit-[контекст].md`.

## Формат вывода

| Параметр тарифа | Starter (Free / Entry) | Professional (Growth) | Enterprise (Custom) |
| :--- | :--- | :--- | :--- |
| [Целевой сегмент] | [Фрилансеры и стартапы] | [Растущие команды (10-50 чел)] | [Крупные корпорации (100+ чел)] |
| [Метрика ценности (Value Metric)] | [До 3 активных проектов] | [До 50 проектов + 100 ГБ] | [Безлимит проектов + Выделенный кластер] |

| Ценовой порог | Значение в рублях | Интерпретация для продукта |
| :--- | :--- | :--- |

### 3. Метрики эффективности монетизации
- **Average Revenue Per Account (ARPA):** Средний чек подписки на один активный аккаунт.
- **Net Expansion Revenue:** Доля прироста выручки от апгрейдов существующих клиентов без учета новых продаж.
- **Freemium-to-Paid Conversion Rate:** Процент бесплатных пользователей, перешедших на платный тариф.
- **Price Elasticity of Demand:** Коэффициент эластичности спроса при изменении стоимости тарифа.

## Правила

- Запрещено повышать цены для действующей базы клиентов без предварительного уведомления минимум за 30 календарных дней.
- Метрика ценности (Value Metric) обязательно должна масштабироваться пропорционально росту бизнеса клиента.
- Тарифная сетка требует строгого ограничения: не более 3-4 публичных планов во избежание паралича выбора.
- Не используй фичи безопасности (SSO, 2FA, Audit Logs) в базовых тарифах: они должны упаковываться в Enterprise.
- Максимальный допустимый процент оттока клиентов при плановом повышении цен не должен превышать 5%.
