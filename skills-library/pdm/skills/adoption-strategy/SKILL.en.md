# Software implementation strategy (adoption-strategy)

Design a plan for introducing new software into the company’s corporate framework, overcome employee resistance and measure engagement metrics.

## Process
1. **Identify barriers of resistance.** Why are employees afraid of a new tool? (Fear of being fired due to automation, too lazy to retrain).
2. **Create a network of Implementation Champions (Change Agents).** Allocation of loyal employees in departments to help colleagues in the field.
3. **Design engagement metrics.** Share of employees logging into the system within 7 days (W1 Adoption Rate).
4. **Save the output** in the current working directory as `adoption-strategy-[context].md`.

## Output Format
```
## Software Implementation Strategy: [Product Name]
- **Overcoming barriers:** conducting webinars with an emphasis on how the software saves 2 hours of routine work per day.
- **Success metric:** 90% of department employees switched to new regulations within 30 days.
```


## Rules

- Write in English.
## Metrics

### Universal Metric Rule
If you propose a metric, answer these 5 questions:
1. **Who owns this metric?**
2. **How often do we track it?**
3. **What events calculate it?**
4. **What is the decision threshold?**
5. **How can it be gamed or corrupted?
