# Onboarding audit



## Process
1. **Record the current onboarding steps.** Number of screens, forms, clicks.
2. **Set an “Aha Moment.”** (For example: the estimator uploaded his estimate and received a PDF download).
3. **Describe the barriers (Friction points).** Long instructions, mandatory settings before starting work.


## Output Format
```
## Onboarding audit: [Product]


- **Redesign recommendations:** [simplification of the onboarding funnel].
```


## Rules

- Write in English.
## Metrics

### Universal Metric Rule
If you propose a metric, answer these 5 questions:
1. **Who owns this metric?**
2. **How often do we track it?**
3. **What events calculate it?**
4. **What is the decision threshold?**
5. **How can it be gamed or corrupted?
