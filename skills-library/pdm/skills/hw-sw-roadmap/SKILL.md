# Дорожная карта аппаратных и программных решений (hw-sw-roadmap)

Спроектировать синхронизированный роадмап для продуктов на стыке железа и софта (IoT, умные устройства, терминалы, дроны, носимая электроника). Скилл согласует длинные циклы производства железа (Tooling, EVT/DVT/PVT, сертификация) с быстрыми Agile-спринтами прошивок (Firmware) и облачного софта.

## Процесс

1. **Синхронизируй аппаратные и программные контрольные точки:** Сопоставь этапы производства железа (EVT -> DVT -> PVT -> Mass Production) со спринтами Firmware, Cloud API и мобильного приложения.
2. **Спроектируй стратегию беспроводного обновления прошивок (OTA):** Двухбанковая архитектура (A/B Partitioning) для защиты от окирпичивания устройств при сбое обновления по воздуху (OTA Failure).
3. **Опиши программу аппаратного тестирования и валидации:** Климатические тесты, вибростенд, тесты на падение, электромагнитную совместимость (EMC) и получение сертификатов соответствия.
4. **Заложи планирование цепочки поставок компонентов (Supply Chain Lead Times):** Учет сроков закупки чипов, печатных плат и пресс-форм с буфером на форс-мажоры.
5. **Сформируй план поддержки устаревающих ревизий плат (Hardware Revisions):** Обеспечение обратной совместимости софта со старыми ревизиями устройств в поле.
6. **Сохрани артефакт** в текущей рабочей директории как `hw-sw-roadmap-[контекст].md`.

### 2. Спецификация архитектуры безопасного OTA обновления

| Параметр OTA | Требование | Механизм реализации |
| :--- | :--- | :--- |
| [Защита от окирпичивания] | [100% гарантия отката] | [Двойная разметка Flash-памяти (Dual Bank A/B)] |
| [Криптографическая защита] | [Защита от подделки прошивки] | [Цифровая подпись ECDSA + проверка хэша SHA-256] |
| [Канареечная раскатка OTA] | [Поэтапное обновление устройств] | [100 устройств -> 1 000 -> Вся база в поле] |

### 3. Метрики эффективности HW/SW продукта
- **OTA Success Rate:** Процент успешных беспроводных обновлений устройств в полевых условиях без сбоев.
- **Hardware Defect Rate (DPPM):** Количество бракованных устройств на миллион выпущенных единиц.
- **Battery Life Optimization:** Фактическое время автономной работы устройства от одного заряда.
- **Schedule Slip Delta:** Отклонение даты запуска массового производства от изначального плана в месяцах.

## Правила

- Запрещено выпускать прошивку в поле без поддержки механизма безопасного дублирования разделов (Dual-Bank A/B OTA).
- Любое изменение схемотехники платы обязательно требует перепроверки обратной совместимости со всеми версиями софта.
- Процесс производства требует обязательного прохождения этапа PVT перед стартом массовой закупки компонентов.
- Не допускай отсутствия уникальных криптографических ключей на каждом физическом устройстве (Hardware Root of Trust).
- Максимальный процент сбоев при установке обновления прошивки по воздуху не должен превышать 0.01%.
