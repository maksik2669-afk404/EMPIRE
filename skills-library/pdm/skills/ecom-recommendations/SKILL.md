# Персональные рекомендации и допродажи в E-com (ecom-recommendations)

Спроектировать рекомендательную систему для интернет-магазина (Product Recommendations Engine): коллаборативная фильтрация, товарные подборки («С этим покупают», «Похожие товары», «Собери образ»), умный апсейл в корзине и персонализация главной витрины.

## Процесс

1. **Спроектируй типы рекомендательных виджетов по страницам:** Главная (Персональный топ), Категории (Бестселлеры), PDP (Комплементарные товары / Cross-sell), Корзина (Быстрые докупки до бесплатной доставки).
2. **Опиши алгоритмы рекомендаций по контексту:** Item-to-Item Collaborative Filtering, Content-Based (похожие по бренду/цвету/материалу) и Market Basket Analysis (правила совместных покупок).
3. **Заложи строгие защитные правила (Recommendation Guardrails):** Запрет показа несовместимых аксессуаров, товаров не в наличии и дублей того же товара.
4. **Спроектируй динамический Cross-sell в корзине (Cart Add-on Engine):** Допродажи с ценой < 20% от текущей корзины для спонтанных покупок в 1 клик.
5. **Опиши систему онлайн A/B тестирования рекомендаций:** Замер инкрементального дохода (Incremental GMV Uplift) и кликабельности (CTR) рекомендательных полок.
6. **Сохрани артефакт** в текущей рабочей директории как `ecom-recommendations-[контекст].md`.

### 2. Спецификация защитных барьеров рекомендаций (Guardrails)
- **Исключение отсутствующих:** Товары со статусом Out-of-Stock или сроком доставки > 3 дней автоматически исключаются из выдачи.
- **Исключение уже купленного:** Товары длительного пользования (смартфоны, холодильники), купленные за последние 60 дней, скрываются из рекомендаций.
- **Ценовой баланс:** Аксессуары в корзине не должны превышать 30% стоимости основного товара.

### 3. Метрики эффективности рекомендательной системы
- **Recommendation Click-Through Rate (CTR):** Процент кликов по товарам в рекомендательных блоках.
- **Recommendation Conversion Rate (CR):** Конверсия из клика по рекомендации в завершенную покупку.
- **Incremental Revenue Lift (% of GMV):** Доля общего товарооборота, сгенерированная непосредственно через рекомендации.
- **Average Order Value (AOV) Uplift:** Прирост среднего чека заказов, содержащих рекомендованные товары.

## Правила

- Запрещено рекомендовать товары, которых нет в наличии на доступных для покупателя складах доставки.
- Рекомендации в корзине обязаны поддерживать добавление товара в заказ в 1 клик без перехода в карточку.
- Система требует автоматического исключения дублирующих категорий при подборе сопутствующих аксессуаров.
- Не допускай показа более 2 рекомендательных полок на одном экране смартфона во избежание визуального шума.
- Максимальное время генерации рекомендательного ответа виджета не должно превышать 60 миллисекунд.
