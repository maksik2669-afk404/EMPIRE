# Анализ защитных барьеров и конкурентных преимуществ (competitive-moat)

Спроектировать долгосрочные конкурентные рвы (Economic Moats по Гамильтону Хелмеру / 7 Powers): сетевые эффекты, стоимость переключения (Switching Costs), масштаб, нематериальные активы, угловые ресурсы и контринновации.

## Процесс

1. **Оцени продукт по 7 силам Хелмера (7 Powers Framework):** 1. Scale Economies, 2. Network Effects, 3. Counter-Positioning, 4. Switching Costs, 5. Branding, 6. Cornered Resource, 7. Process Power.
2. **Рассчитай силу барьеров переключения (Switching Costs):** Оценка затрат времени и денег клиента при переходе на продукт конкурента (перенос данных, переобучение персонала, потеря истории).
3. **Спроектируй сетевые эффекты (Network Effects):** Двусторонние прямые и косвенные сетевые эффекты, увеличивающие ценность продукта с каждым новым пользователем.
4. **Опиши контринновационную стратегию (Counter-Positioning):** Бизнес-модель, которую традиционные лидеры рынка не могут скопировать без каннибализации собственного основного бизнеса.
5. **Сформируй роадмап укрепления рва на 2-3 года:** Конкретные продуктовые инициативы, углубляющие защиту от копирования конкурентами.
6. **Сохрани артефакт** в текущей рабочей директории как `competitive-moat-[контекст].md`.

### 2. Спецификация инициатив по укреплению барьеров ухода (Switching Costs)
- **Накопление ценности данных (Data Moat):** Автоматическое построение исторических трендов за 3 года, которые невозможно экспортировать к конкуренту без потери контекста.
- **Глубокие интеграции:** Создание 20+ двусторонних коннекторов к популярным корпоративным системам.
- **Сертификация специалистов:** Программа обучения администраторов продукта с выдачей именных дипломов.

### 3. Метрики устойчивости конкурентного рва
- **Annual Gross Revenue Retention (GRR):** Процент удержания базовой выручки существующих клиентов (Target: > 95%).
- **Competitive Win/Loss Ratio:** Соотношение выигранных сделок против ключевых конкурентов в прямых сравнениях.
- **Price Premium Tolerance:** Способность удерживать цену на 15-20% выше аналогов без потери доли рынка.
- **Time to Duplicate Feature:** Время в месяцах, необходимое сильнейшему конкуренту для полного копирования фичи.

## Правила

- Запрещено называть фичу "конкурентным преимуществом", если она может быть скопирована конкурентом быстрее чем за 3 месяца.
- Анализ обязателен к подтверждению конкретными цифровыми метриками удержания клиентов (GRR/NRR).
- Стратегия требует обязательного выделения минимум 2 доминирующих сил из 7 Powers Хелмера.
- Не допускай иллюзии защиты за счет патентов без развитых сетевых эффектов или барьеров переключения.
- Минимальный целевой уровень удержания выручки (GRR) для подтверждения наличия рва должен составлять не менее 90%.
