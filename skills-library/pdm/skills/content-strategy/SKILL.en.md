# Product content strategy

Design a content management strategy for media and streaming platforms (movies, music, podcasts) to maximize retention time (engagement) and LTV.

## Process
1. **Link content to subscription.** How content attracts users (Acquisition content) and how it retains it (Retention content).
2. **Define content performance metrics.** Completion Rate, Skip Rate, Share Rate.
3. **Design a balance between manual curation and algorithms.**
4. **Save the output** in the current working directory as `content-strategy-[context].md`.

## Output Format
```
## Content Strategy: [Platform]
- **Target engagement metrics:** [watch time, listenability]
- **Content distribution priority:** [curated playlists vs. AI recommendations].
```


## Rules

- Write in English.
## Metrics

### Universal Metric Rule
If you propose a metric, answer these 5 questions:
1. **Who owns this metric?**
2. **How often do we track it?**
3. **What events calculate it?**
4. **What is the decision threshold?**
5. **How can it be gamed or corrupted?
