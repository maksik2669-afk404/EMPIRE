## Rules

- Do not evaluate all initiatives with the same framework without taking into account stage.
- Indicate the opportunity cost of resources.
- Closing the initiative is a valid product solution.
- Write in English.

## Metrics

### Universal Metric Rule
If you propose a metric, answer these 5 questions:
1. **Who owns this metric?**
2. **How often do we track it?**
3. **What events calculate it?**
4. **What is the decision threshold?**
5. **How can it be gamed or corrupted?
