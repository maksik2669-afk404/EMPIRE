# HR-портал развития и оценки сотрудников (hr-portal-growth)

Спроектировать функциональность портала управления талантами (Talent Management): матрицы компетенций, адаптация новичков (План 30-60-90), Performance Review (Оценка 360), ИПР (Индивидуальные планы развития) и планирование кадрового резерва (Succession Planning).

## Процесс

1. **Спроектируй структуру онбординга (Onboarding Journey):** Чеклисты первого дня, постановка целей на испытательный срок (30-60-90 дней), назначение бадди и наставника.
2. **Опиши механику Performance Review и Оценки 360:** Сбор фидбека от коллег, самооценка, оценка руководителя, калибровка оценок на комитетах (Calibration Sessions).
3. **Спроектируй конструктор ИПР и матрицу навыков (Skill Matrix):** Определение сильных сторон и зон роста, подбор обучающих курсов и менторских программ под цели сотрудника.
4. **Разработай модуль One-on-One встреч:** Совместное ведение повесток 1:1, фиксация договоренностей (Action Items) и отслеживание динамики настроения (Mood Tracker).
5. **Сформируй аналитику талантов для руководства (Talent Grid 9-Box):** Распределение сотрудников по матрице Потенциал vs Результативность.
6. **Сохрани артефакт** в текущей рабочей директории как `hr-portal-growth-[контекст].md`.

## Формат вывода

### 1. Архитектура цикла Performance Review (Оценка 360)

| Этап цикла | Участники | Действие в системе | Срок выполнения |
| :--- | :--- | :--- | :--- |
| [1. Самооценка] | [Сотрудник] | [Заполнение анкеты достижений за полугодие] | [1 неделя] |
| [2. Сбор 360 фидбека] | [3-5 коллег + Смежники] | [Оценка поведенческих компетенций по шкале 1-5] | [2 недели] |
| [3. Оценка руководителя] | [Team Lead / Manager] | [Сводный отзыв и предложение по грейду/бонусу] | [1 неделя] |
| [4. Калибровка] | [Калибровочный комитет] | [Нормализация оценок по подразделению (Bell Curve)] | [3 дня] |
| [5. Фидбек-сессия] | [Лид + Сотрудник] | [Фиксация ИПР на следующий период] | [1 неделя] |

### 2. Спецификация 9-Box Talent Matrix

| Категория 9-Box | Характеристика сотрудника | Рекомендуемое действие | План развития |
| :--- | :--- | :--- | :--- |
| [Box 1: Top Talent] | [Высокий потенциал + Высокий перформанс] | [Промоушн / Включение в кадровый резерв] | [Executive менторинг] |
| [Box 2: Core Performer] | [Средний потенциал + Высокий перформанс] | [Удержание, премирование, расширение задач] | [Углубление экспертизы] |
| [Box 3: Underperformer] | [Низкий потенциал + Низкий перформанс] | [PIP (Performance Improvement Plan) 30 дней] | [Четкие KPI / Ротация] |

### 3. Метрики эффективности HR-портала
- **Review Cycle Completion Rate:** Процент сотрудников, завершивших цикл оценки в установленные сроки.
- **Probation Pass Rate:** Доля успешного прохождения испытательного срока новичками.
- **Internal Mobility Rate:** Процент открытых вакансий, закрытых внутренними кандидатами из кадрового резерва.
- **Performance Evaluation Fairness (CSAT):** Оценка прозрачности и справедливости процесса оценки сотрудниками.

## Правила

- Запрещено проводить калибровку оценок без предварительного заполнения самооценки сотрудником.
- Каждый цикл Performance Review обязательно должен завершаться сформированным и подписанным ИПР на следующий период.
- При выставлении оценки "Ниже ожиданий" система требует обязательного указания конкретных фактов и запуска плана PIP.
- Не допускай раскрытия анонимности респондентов при сборе 360-фидбека: отображаются только агрегированные баллы (минимум 3 отзыва).
- Максимальная длительность анкеты оценки не должна превышать 15 минут заполнения.
