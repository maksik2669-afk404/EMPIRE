# 

Design a matrix of trigger notifications (Push/SMS/Email) to encourage users to return to the product while maintaining a balance of engagement and protection from opt-outs.

## Process
1. **Create a matrix of events.**
2. **Define delivery channels.** SMS - for critical (transactions), Push - for contextual, Email - for long digests.

4. **Save the output** in the current working directory as `notification-strategy-[context].md`.

## Output Format
```
## Notification Matrix: [Product]

### 1. Delivery rules (Notification Matrix)

|---|---|---|---|
| **Registration of transaction** | SMS + Push | Instantly | “The transaction was registered in Rosreestr. Expect accounts to be revealed" |
| **Abandoned Cart** | Push | 2 hours | “The products are waiting in the basket. Complete your order" |
```
