# Внутренняя CRM подбора персонала и ATS (internal-recruitment-crm)

Спроектировать специализированную систему управления наймом (Applicant Tracking System / ATS): парсинг резюме с джоб-бордов, воронка кандидатов, интеграция с календарями интервьюеров, скоринг и аналитика стоимости найма (Cost-per-Hire).

## Процесс

1. **Спроектируй канбан-воронку подбора (Hiring Pipeline):** Настрой этапы: Скрининг -> Первичное интервью -> Тестовое задание -> Техническая секция -> Финал -> Оффер -> Выход.
2. **Опиши модуль парсинга и обогащения резюме:** Автоматический импорт кандидатов из HH/LinkedIn/Хабр Карьеры, извлечение контактов, опыта и навыков в единый профиль.
3. **Спроектируй планировщик интервью и scorecard оценки:** Синхронизация со слотами в календарях нанимающих менеджеров, единая форма оценки (Scorecard) по компетенциям.
4. **Организуй модуль офферов и согласований:** Конструктор шаблонов офферов с динамическими полями (грейд, оклад, бонусы), маршрут согласования с CFO/HRD.
5. **Сформируй сквозную аналитику рекрутмента:** Отчеты по источникам кандидатов, конверсиям воронки, Time-to-Hire и причинам отказов.
6. **Сохрани артефакт** в текущей рабочей директории как `internal-recruitment-crm-[контекст].md`.

## Формат вывода

### 1. Этапы воронки подбора и SLA этапов

| Этап воронки ATS | Ответственная роль | Действие в системе | Максимальный SLA на этапе |
| :--- | :--- | :--- | :--- |
| [1. Входящий отклик] | [Рекрутер] | [Скрининг резюме, звонок-знакомство] | [24 часа] |
| [2. Оценка тестового] | [Нанимающий менеджер] | [Проверка кода/кейса по Scorecard] | [48 часов] |
| [3. Секция интервью] | [Интервьюеры] | [Заполнение формы оценки сразу после встречи] | [2 часа после интервью] |
| [4. Формирование оффера] | [HR Lead / C-level] | [Электронное согласование условий] | [24 часа] |

### 2. Спецификация формы оценки кандидата (Interview Scorecard)
- **Оцениваемые компетенции:** Hard Skills (по грейду вакансии), Soft Skills (командность, решение конфликтов), Culture Fit.
- **Шкала оценки:** 1 (Strong No Hire) -> 2 (No Hire) -> 3 (Hire) -> 4 (Strong Hire).
- **Обязательное поле:** Текстовое обоснование с примерами ответов кандидата (минимум 150 символов).

### 3. Метрики эффективности системы найма
- **Time to Hire (TTH):** Среднее количество дней от открытия вакансии до принятия оффера кандидатом.
- **Offer Acceptance Rate (OAR):** Процент кандидатов, принявших предложение о работе.
- **Cost per Hire (CPH):** Полная стоимость закрытия одной позиции (реклама + агентства + время команды).
- **Candidate Net Promoter Score (cNPS):** Оценка процесса найма кандидатами (включая тех, кто получил отказ).

## Правила

- Запрещено переводить кандидата на следующий этап воронки без заполненного Scorecard с предыдущего этапа.
- Каждый отказ кандидату обязательно должен сопровождаться вежливым уведомлением с указанием конструктивной причины.
- Система требует строгого соблюдения 152-ФЗ: автоматическое получение согласия на обработку ПДн при импорте резюме.
- Не допускай зависания кандидатов на этапе проверки тестового задания более 72 часов.
- Максимальное количество этапов интервью для одной вакансии не должно превышать 4 встреч.
