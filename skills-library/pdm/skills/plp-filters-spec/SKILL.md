# Спецификация каталога товаров, фильтров и листинга (plp-filters-spec)

Спроектировать листинг товаров (Product Listing Page / PLP): многоуровневую систему фасетных фильтров (Faceted Search), сортировки, бесконечный скролл vs пагинацию и быстрый просмотр (Quick View).

## Процесс

1. **Спроектируй фасетную систему фильтрации (Faceted Navigation):** Динамические фильтры под категорию (цена-слайдер, бренд, цвет, размер, технические параметры) с показом количества товаров в скобках.
2. **Опиши сортировки и умное ранжирование листинга:** Сортировка по популярности, цене, новинкам, скидке, скорости доставки и отзывам.
3. **Спроектируй мобильный UX фильтров (Bottom Sheet Filter):** Полноэкранная шторка фильтров с мгновенным пересчетом подходящих товаров и кнопкой «Показать 142 товара».
4. **Разработай логику пагинации и ленивой загрузки (Pagination vs Infinite Scroll):** Подгрузка товаров батчами по 24-48 SKU с сохранением позиции скролла при возврате из карточки товара.
5. **Спроектируй бейджи и быстрые действия на карточке листинга:** Добавление в избранное, выбор размера в 1 клик, бейджи акций («-30%», «Хит продаж»).
6. **Сохрани артефакт** в текущей рабочей директории как `plp-filters-spec-[контекст].md`.

## Формат вывода

### 1. Архитектура элементов карточки товара в листинге (PLP Grid)

| Элемент карточки на PLP | Интерактивное действие | Назначение |
| :--- | :--- | :--- |
| [Превью фото (Карусель)] | [Свайп/наведение для просмотра 3-4 фото] | [Быстрая оценка товара без перехода на PDP] |
| [Бейдж скидки и плашка акции] | [Статичный цветной бейдж в углу фото] | [Привлечение внимания к промо-предложениям] |

### 2. Спецификация логики фасетных фильтров (Faceted Filters)
- **Мгновенный пересчет (Dynamic Count):** При выборе любого фильтра все остальные фильтры обновляют счетчики доступных товаров.
- **Очистка и сброс:** Кнопка «Сбросить все» + удаление каждого фильтра по отдельности через кликабельные теги (Chips).
- **SEO-friendly URL:** Формирование понятных ЧПУ ссылок для популярных комбинаций фильтров (например, `/catalog/shoes/nike-black/`).

### 3. Метрики эффективности каталога и листинга (PLP KPIs)
- **PLP-to-PDP Click-Through Rate:** Процент переходов из листинга каталога на детальные карточки товаров.
- **Filter Usage Rate:** Доля посетителей каталога, применивших хотя бы один фасетный фильтр.
- **Zero Results Filter Rate:** Процент комбинаций фильтров, вернувших нулевую выдачу (Target: < 0.1%).
- **Scroll Depth on Category Page:** Глубина просмотра товарного листинга в экранах/страницах.

## Правила

- Запрещено блокировать интерфейс и перезагружать страницу целиком при каждом клике на чекбокс фильтра (AJAX/Fetch only).
- При возврате назад из карточки товара пользователь обязан возвращаться строго на ту же позицию скролла на PLP.
- Система фильтрации требует автоматического скрытия взаимоисключающих параметров с нулевым результатом.
- Не допускай отсутствия быстрого сброса примененных фильтров в виде удобных тегов-чипсов над листингом.
- Максимальное время перерисовки товарного листинга при применении фильтра не должно превышать 150 миллисекунд.
