# Структура и дизайн продуктовых презентаций (presentation-design)

Спроектировать структуру убедительной продуктовой презентации (Executive Pitch Deck / Strategy Presentation): пирамида Минто (SCQA), нарративный сторителлинг, верстка слайдов без перегруза («1 мысль на 1 слайд») и дизайн ключевых визуалов.

## Процесс

1. **Сформируй нарративную структуру по пирамиде Минто (SCQA):** Ситуация (Situation) -> Осложнение (Complication) -> Вопрос (Question) -> Ответ / Решение (Answer).
2. **Определи ключевую мысль каждого слайда (Headline Lead):** Заголовки слайдов в виде законченных утверждений, которые складываются в единый связанный рассказ при чтении подряд.
3. **Примени правило визуальной иерархии («1 слайд = 1 ключевая идея»):** Отсечение текстовых простыней, использование акцентных цифр, емких таблиц и схем вместо буллетов.
4. **Спроектируй структуру 10-слайдовой презентации:** 1. Заглавный, 2. Контекст рынка, 3. Острая проблема, 4. Наше решение, 5. Тракшн и доказательства, 6. Бизнес-модель, 7. Роадмап, 8. Инвестиции, 9. Команда, 10. Призыв к действию (CTA).
5. **Подготовь приложение и ответы на каверзные вопросы (Appendix & FAQ):** Резервные слайды с детальными расчетами для секции Q&A.
6. **Сохрани артефакт** в текущей рабочей директории как `presentation-design-[контекст].md`.

## Формат вывода

### 1. Послайдовая раскадровка продуктовой презентации (Storyline Deck)

| № Слайда | Тип слайда | Заголовок-утверждение (Action Headline) | Ключевой визуал / Элемент на слайде |
| :--- | :--- | :--- | :--- |
| **Слайд 1** | [Титул / Крючок] | [Автономная логистика: Сокращаем расходы на доставку на 25%] | [Логотип + Ключевой слоган в 1 строку] |
| **Слайд 2** | [Проблема / Боль] | [Ручная диспетчеризация съедает до 30% маржинальности ритейлеров] | [Крупная цифра '1.2 млрд руб потерь' + иконки болей] |
| **Слайд 3** | [Наше решение] | [AI-платформа распределяет 5000 заказов за 10 секунд] | [Скриншот интерфейса карты с живыми курьерами] |
| **Слайд 4** | [Тракшн / Результаты] | [Мы выросли в 3 раза за год и достигли $100k MRR] | [График роста ARR по когортам + логотипы клиентов] |
| **Слайд 5** | [Запрос / Финал] | [Привлекаем $1.5M для масштабирования продаж и экспансии] | [Таблица раунда Deal Terms + контакты фаундеров] |

### 2. Спецификация дизайна слайда (Design Standard)
- **Правило 3 секунд:** Смысл слайда должен считываться зрителем менее чем за 3 секунды.
- **Ограничение текста:** Не более 30-40 слов на одном слайде.
- **Цветовые акценты:** 1 доминирующий цвет бренда + 1 контрастный цвет для фокуса внимания на главной цифре.

### 3. Метрики эффективности презентации
- **Audience Engagement Score:** Удержание внимания слушателей на протяжении всего питча.
- **Pitch-to-Next-Meeting Conversion:** Процент встреч, завершившихся переходом на следующий этап (Due Diligence / Бюджет).
- **Q&A Readiness:** Способность ответить на 100% вопросов инвесторов с опорой на слайды приложения.
- **Storyline Flow Clarity:** Оценка логичности перехода между слайдами независимыми экспертами.

## Правила

- Запрещено использовать заголовки-существительные (например: "Наши результаты") вместо заголовков-утверждений.
- Слайд обязан содержать строго одну ключевую идею без визуального захламления мелкими деталями.
- Презентация требует обязательного наличия резервных слайдов приложения (Appendix) для глубоких финансовых вопросов.
- Не допускай использования мелкого нечитаемого шрифта (размер основного текста строго от 18pt и выше).
- Общее количество слайдов основного питча не должно превышать 10-12 слайдов на 15 минут выступления.
