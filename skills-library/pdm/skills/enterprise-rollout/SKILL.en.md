# Implementation in Enterprise (enterprise-rollout)

Develop a phased rollout plan for a new IT tool in a large company and a change management strategy among employees.

## Process
1. **Describe the phases of implementation.** Pilot department -> Training -> Scaling -> Full transition.
2. **Design a training and adaptation program.** Webinars, interactive tips, knowledge base.
3. **Define implementation metrics.** Share of active employees (Adoption Rate), speed of task closure in the new tool.
4. **Save the output** in the current working directory as `enterprise-rollout-[context].md`.

## Output Format
```
## Software implementation plan: [Name of client company]
- **Launch phases:** Pilot for 50 users (4 weeks) -> Rollout to departments (8 weeks).
- **Adoption metrics:** Adoption Rate in the first month > 80%.
```


## Rules

- Write in English.
## Metrics

### Universal Metric Rule
If you propose a metric, answer these 5 questions:
1. **Who owns this metric?**
2. **How often do we track it?**
3. **What events calculate it?**
4. **What is the decision threshold?**
5. **How can it be gamed or corrupted?
