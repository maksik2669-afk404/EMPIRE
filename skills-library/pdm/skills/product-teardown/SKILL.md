# Глубинный разбор продукта и продуктовых решений (product-teardown)

Провести всесторонний продуктовый разбор (Product Teardown / Feature Teardown) любого цифрового сервиса: стратегия, UX/UI паттерны, петли удержания, монетизация, уязвимости и конкретные рекомендации «Если бы я был PM».

## Процесс

1. **Исследуй продукт и целевую аудиторию:** Сбор данных через веб-поиск, анализ отзывов в сторах, онбординга и ключевых сценариев.
2. **Декомпозируй ключевую петлю взаимодействия (Core Loop):** Основной сценарий действий пользователя: Триггер -> Действие -> Награда -> Инвестиция.
3. **Проанализируй сильные UX и продуктовые решения:** Топ-3 решения, которые вызывают восторг и удерживают пользователей в продукте.
4. **Выяви слабые места и уязвимости (Product Weaknesses):** Трение в воронке, непонятный онбординг, перегруженные экраны, навязчивая монетизация.
5. **Сформулируй вердикт и бэклог улучшений («Если бы я был PM»):** 2-3 конкретные гипотезы с прогнозом влияния на метрики и сложностью реализации.
6. **Сохрани артефакт** в текущей рабочей директории как `product-teardown-[контекст].md`.

## Формат вывода

### 1. Паспорт продукта и продуктовый разбор (Teardown Summary)

| Параметр продукта | Анализ и оценка |
| :--- | :--- |
| **Суть продукта (One-Liner)** | [Мобильный трекер привычек с социальной геймификацией и AI-коучем] |
| **Целевая аудитория** | [Молодые профессионалы (20-35 лет), стремящиеся к продуктивности и балансу] |
| **Ключевая петля (Core Loop)** | [Утренний пуш -> Отметка привычки -> Получение опыта/кристаллов -> Соревнование в гильдии] |
| **Модель монетизации** | [Freemium: Базовый трекер бесплатно, AI-коучинг и детальная аналитика по подписке $9.99/мес] |
| **Защитный ров (Moat)** | [Социальный граф и накопленная история личного прогресса за годы] |

### 2. Спецификация анализа сильных и слабых сторон

| Продуктовое решение | Статус | Анализ и почему это работает / не работает |
| :--- | :--- | :--- |
| [Виджет на рабочий стол] | [👍 Сила] | [Снижает барьер отметки до 1 тапа без открытия приложения, D7 Retention +18%] |
| [Онбординг из 12 экранов] | [👎 Слабость] | [Слишком длинный опросник до показа первой ценности, отвал 35% новичков] |
| [Пейвол на 2-й минуте] | [👎 Слабость] | [Агрессивный показ годовой подписки без демонстрации Aha-момента] |

### 3. Рекомендации продакт-менеджеру («Если бы я был PM»)
- **Инициатива 1 (Сокращение онбординга):** Уменьшить опросник до 3 шагов, дать возможность сразу создать первую привычку.
- **Инициатива 2 (Reverse Trial):** Предоставлять 7 дней полного премиума бесплатно без привязки карты.
- **Инициатива 3 (Социальный шеринг):** Автоматическая генерация красивых сторис с недельными достижениями для соцсетей.

### 4. Метрики эффективности продуктового разбора
- **Actionable Insights Count:** Количество внедренных в бэклог продуктовых гипотез по итогам разбора.
- **Tear-down Depth Score:** Полнота охвата продуктовых слоев (UX, Монетизация, Архитектура, Стратегия).
- **Competitor Flaw Exploitation:** Успешное использование выявленных слабостей конкурентов в собственном позиционировании.

## Правила

- Запрещено делать поверхностный разбор без прохождения полного пользовательского пути от регистрации до покупки.
- Каждый разбор обязан иметь четкую субъективную позицию (Opinionated Analysis) вместо нейтрального перечисления фич.
- Анализ требует обязательного выделения ключевой петли удержания (Core Interaction Loop).
- Не допускай общих банальных рекомендаций: предложения улучшений должны быть предельно конкретными.
- Итоговый разбор обязан содержать конкретный список действий с оценкой эффекта и сложности (Impact/Effort).
