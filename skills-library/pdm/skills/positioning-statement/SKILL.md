# Формулирование позиционирования продукта (positioning-statement)

Спроектировать каноническое позиционирование продукта по фреймворку Джеффри Мура (Crossing the Chasm) и Эйприл Данфорд (Obviously Awesome): категория, целевой сегмент, ключевое отличие, доказательства превосходства и уникальная ценность.

## Процесс

1. **Определи конкурентные альтернативы (Competitive Alternatives):** Что клиенты используют сейчас при отсутствии нашего продукта (Excel, конкуренты, ручной труд).
2. **Выдели уникальные дифференциаторы (Unique Attributes):** Какие уникальные фичи и технологии есть только у нас и не могут быть легко скопированы.
3. **Свяжи атрибуты с реальной ценностью (Value Mapping):** Какую осязаемую пользу эти уникальные атрибуты приносят конкретному целевому клиенту.
4. **Сформулируй категориальный фрейм (Market Category):** В какой категории продукт побеждает безоговорочно (создание новой подкатегории).
5. **Собери итоговую формулу Мура и Elevator Pitch:** Лаконичное позиционирование в 1-2 предложениях для маркетинга и продаж.
6. **Сохрани артефакт** в текущей рабочей директории как `positioning-statement-[контекст].md`.

## Формат вывода

### 1. Канонический шаблон позиционирования по Джеффри Муру

- **Для:** [B2B компаний среднего размера с собственным автопарком доставки],
- **Которые:** [устали от ручной диспетчеризации и постоянных срывов сроков доставки курьерами],
- **Наш продукт [Название]:** [является автономной платформой диспетчеризации и маршрутизации на базе AI],
- **Которая:** [автоматически распределяет сотни заказов за 10 секунд и сокращает холостой пробег на 25%],
- **В отличие от:** [громоздких и дорогих Enterprise TMS-систем или ручных таблиц Excel],
- **Наш продукт:** [внедряется за 1 день без интеграторов и предоставляет открытый API с оплатой за заказ].

### 2. Спецификация 5 элементов позиционирования по Эйприл Данфорд

| Элемент позиционирования | Формулировка для продукта |
| :--- | :--- |
| **1. Конкурентные альтернативы** | [Ручное планирование в Excel + координация через чаты в мессенджерах] |
| **2. Уникальные возможности** | [ML-алгоритм батч-маршрутизации + нативное приложение курьера с оффлайн-режимом] |
| **3. Доказанная ценность** | [Сокращение затрат на логистику на 20% + освобождение 3 часов времени диспетчера ежедневно] |
| **4. Целевой сегмент (Best-Fit ICP)** | [Быстрорастущие e-grocery и ритейл сети с объемом 200 - 2 000 доставок в день] |
| **5. Рыночная категория** | [Self-serve платформа умной доставки последней мили (Smart Last-Mile Platform)] |

### 3. Метрики эффективности позиционирования
- **Message Clarity Score:** Процент потенциальных клиентов, правильно понявших суть продукта после 5-секундного просмотра лендинга.
- **Inbound Lead Quality Ratio:** Доля входящих лидов, точно попадающих в описанный сегмент позиционирования.
- **Sales Pitch Conversion Lift:** Прирост конверсии первого звонка сейлзов после внедрения нового Elevator Pitch.
- **Competitive Win Rate:** Процент побед над конкурентами благодаря четкой дифференциации.

## Правила

- Запрещено использовать общие пустые клише (например: "лучший инновационный сервис") в тексте позиционирования.
- Позиционирование обязательно должно содержать четкую привязку к конкурентной альтернативе (от чего мы отстраиваемся).
- Каждое заявленное преимущество обязано подкрепляться проверяемой функциональной возможностью (Proof Point).
- Не допускай попыток позиционировать продукт одновременно для диаметрально противоположных аудиторий.
- Текст Elevator Pitch обязан быть лаконичным и читаться вслух менее чем за 30 секунд.
