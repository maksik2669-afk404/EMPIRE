# B2B corporate training (b2b-edtech)

Develop requirements for an LMS system (Learning Management System) for the corporate sector: employee training, skills assessment, integration.

## Process
1. **Describe the roles.** Company administrator (HR), Manager, Employee (student).
2. **Design an HR office.** Assigning courses to employees, tracking progress, uploading reports on completion of mandatory compliance training.
3. **Determine business ROI for the company.** Reducing costs for employee adaptation (onboarding time), increasing skills.
4. **Save the output** in the current working directory as `b2b-edtech-[context].md`.

## Output Format
```
## B2B EdTech System Specification: [Title]
- **HR office:** dashboard of course progress by department.
- **Integration with the IT circuit:** import of organizational structure from 1C: ZUP / Active Directory.
- **Compliance module:** automatic blocking of access to work systems if the annual information security test is overdue.
```

- Write in English.

### Universal Metric Rule

1. **Who owns this metric?**
2. **How often do we track it?**
3. **What events calculate it?**
4. **What is the decision threshold?**
5. **How can it be gamed or corrupted?
