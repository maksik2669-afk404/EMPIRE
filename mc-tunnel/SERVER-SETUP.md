# Настройка прикрывающего сервера

Сервер должен быть **настоящим играбельным Minecraft-сервером**, а не пустышкой
под туннель. Его «настоящесть» — половина защиты (бьёт активное зондирование и
блок-листы). Пустой сервер, куда никто не заходит, эту половину не даёт.

## 1. Где брать VPS

- **За пределами страны с блокировками.** Exit-нода внутри того же файрвола
  бесполезна как выход. Для РФ-рынка хороша Финляндия (Хельсинки): вне цензуры,
  но низкий пинг до Москвы (~20 мс по заявкам провайдеров — проверь сам).
- **Спеки:** 2–4 vCPU / 4–8 ГБ RAM / NVMe / ≥10 ТБ трафика / 1 Гбит/с. Ryzen
  9950X и подобное — оверкилл, если на сервере не реально людно.
- **Оплата криптой** снижает привязку личности к exit-ноде.
- **Проверь до покупки:** IP/подсеть провайдера не должны быть уже в блок-листе
  изнутри страны. Бери триал или провайдера с заменой IP; протестируй пинг и
  достижимость порта 25565 изнутри ДО годовой оплаты.

## 2. Сервер

```bash
# Debian/Ubuntu
sudo apt update && sudo apt install -y openjdk-21-jre-headless
mkdir -p ~/mc && cd ~/mc
# скачай Paper 1.20.1 (paper-1.20.1-<build>.jar) с papermc.io
echo "eula=true" > eula.txt
java -Xms2G -Xmx6G -jar paper-1.20.1.jar nogui
```

В `server.properties`:

```
online-mode=false        # milestone 1 использует offline-вход (станет true в m2)
server-port=25565
motd=...                  # сделай MOTD, похожий на обычный публичный сервер
max-players=50
```

Положи `McTunnel.jar` в `plugins/`, перезапусти. В логах:
`McTunnel active on channel 'mctunnel:d'`.

`plugins/McTunnel/config.yml`:

```yaml
channel: "mctunnel:d"     # то же значение в --channel у клиента
dial-timeout-ms: 10000
```

## 3. Прогрев (критично для скрытности)

Свежий сервер без истории — слабое прикрытие. Первые недели:

- **Пусти реальных игроков.** Публичный MOTD, пара знакомых, которые правда
  играют. Настоящие сессии создают фон, в котором тонет туннель.
- **Держи аптайм 24/7.** Перезапуски и простои нетипичны для живого сервера.
- **Не выдавай себя трафиком.** Пока нет временного шейпинга (milestone 3) не
  гоняй через него закачки — объёмные бурсты на «геймерском» сервере заметны.
- Чем дольше сервер живёт с нормальной активностью, тем выше доверие к его IP.

## 4. Проверка

1. На сервере плагин поднялся (строка в логе).
2. Клиент заходит: `./mctun-client --server <ip>:25565 --user Tester` →
   `joined ... as "Tester"`.
3. Через SOCKS5 открой сайт: `curl -x socks5h://127.0.0.1:1080 https://example.com`.
4. На самом сервере игрок «Tester» виден в онлайне как обычный игрок.

## 5. Гигиена

- Канал — единственный секрет milestone 1. Держи `channel` неочевидным;
  настоящая аутентификация туннеля придёт в milestone 4.
- Не логируй на сервере содержимое туннеля.
- Разворачивай только там, где распоряжаешься сетью сам.
